# School & Teacher Administration System

An internal enterprise web platform engineered to streamline administrative workflows for teachers and school staff, including curriculum guidelines, administrative reporting, and academic data management.

> **Note for Recruiters:** This project was originally developed under an NDA for an enterprise academic institution. Sensitive configuration files, database credentials, and internal assets have been sanitized or omitted for portfolio demonstration purposes.

## 🚀 Key Features & Modules

* **Teacher & Curriculum Administration:** Centralized management system for teacher administrative tasks, grading workflows, and curriculum documentation (such as K-13 guidelines).
* **Interactive Data Tables:** Integrated dynamic Datatables for efficient search, filtering, and pagination of large datasets.
* **Role-Based Access Control (RBAC):** Custom authorization modules ensuring secure access levels for teachers, department heads, and administrative staff.
* **Responsive UI/UX:** Built with Bootstrap framework to ensure responsive layouts across different screen sizes.

---

## 🛠️ Tools & Technologies Used

* **Backend:** PHP 7.x, CodeIgniter 3 Framework
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 3, DataTables, jQuery, AJAX
* **Database:** MySQL
* **Architecture:** Model-View-Controller (MVC)

---

## 📐 Key Engineering Highlights

* Designed scalable database structures to handle complex data relationships between teachers, classes, and administrative records.
* Implemented asynchronous data updates via AJAX to enhance user experience and avoid unnecessary page reloads.
* Formatted input sanitization and secure authentication mechanisms to maintain data integrity across school operations.
